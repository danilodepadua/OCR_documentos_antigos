# OCR_documentos_antigos
Aplicação de OCR em: Registro Civil do estado (Pernambuco pelo family search) ou Arquivos de Periódicos (Pela Hemeroteca) ou avaliação de redação (Kaggle?)

## Modelo treinado

Os arquivos gerados em `Back-End/saved_model/` não são versionados por serem grandes. Para gerá-los localmente, execute `python train.py` dentro da pasta `Back-End`.
